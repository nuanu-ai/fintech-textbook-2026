## Правила чтения

`confirmed` означает соответствие прочитанному источнику **в указанном scope**, а не успешную транзакцию или независимое одобрение главы. Датированный announcement подтверждает сообщение о событии, не все дальнейшие стадии. `rejected` относится к сформулированному мифу. Синтетические числа и операционные схемы помечены в [главе](README.md); их арифметика проверена отдельно, они не рыночные данные.

Общие поля каждой карточки: `as_of=2026-09-15`; `last_checked_at=2026-09-15 UTC`; `reviewer=part_06_research (author)`; `review_status=see_REVIEW.md` для независимого review. `effective_to=unknown` для нормы/договора, `not_applicable` для остальных. По умолчанию `relation=supports`; для rejected — `contradicts` ложный тезис; для hypothesis/open — `context`. `review_trigger`: обновление источника/закона, смена сети/версии/договора, новое CBDC решение либо подготовка к реальному запуску; до него нужна повторная проверка динамических условий. `confidence_basis`: прямое чтение названного объёма, а не число ссылок; `conflicts/resolution` отражены в ограничениях и [журнале](Заметки-исследования.md).
