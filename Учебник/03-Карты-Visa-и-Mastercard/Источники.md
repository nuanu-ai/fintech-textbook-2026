## Как читать карточки

Реестр соответствует SOURCE_DATASET_SCHEMA.md. Общие поля ниже наследуются **каждой** карточкой, если она не переопределяет их:

- `snapshot_id = <source_id>@2026-09-15`; это идентификатор чтения конкретной версии, **не архивная копия**. `supersedes = none`; `accessed_at = 2026-09-15, Asia/Makassar (UTC+08), date_precision доступа = day`.
- `url = canonical_url = ссылка карточки`, если отдельно не указан redirect. `doi = unknown`; `updated_at = unknown`; `effective_to = unknown`; для не-нормативной страницы `effective_from/to = not_applicable`. `origin_source_id = self`.
- `local_path = none`, `sha256 = not_applicable`: издательские PDF, изображения и полные тексты не сохранены в базе. Часть PDF прочитана через извлечение текста из официального URL в памяти; это чтение оригинала, не авторского зеркала.
- `rights`: хранение/распространение полной копии — `unknown, not exercised`; иллюстрации — `unknown, not used`; пересказ своими словами с attribution, без длинного цитирования. Публичная доступность не трактуется как лицензия. `rights_basis_url = URL карточки / copyright notice документа`; явные особенности указаны ниже.
- `reviewer = see_REVIEW.md`, `reviewed_at = see_REVIEW.md`: автор проверил чтение и трассировку; охват, дата и вердикт независимого агента — в REVIEW.md.
- `access_status = partial_text` у больших документов означает: прочитаны перечисленные разделы, не весь документ. `full_text` у короткой страницы — прочитан основной текст; меню, другие страницы и связанные спецификации автоматически в scope не входят.
- Даты редакции/публикации и effective date различаются. Для rulebook без единого подтвержденного effective date стоит `effective_from = provision_specific`; точная дата используемого положения приводится в CLAIMS. Дата обложки не превращается в дату начала действия каждого пункта.
- `independence_group` по издателю: Visa/Verifi = `visa`; Mastercard/Ethoca = `mastercard`; независимость страниц одной группы не утверждается. Коммерческий интерес — продвижение собственной сети и сервисов; заявленные marketing uplift/coverage metrics не используются как независимая оценка результата.
