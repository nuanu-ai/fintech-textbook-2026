# Редакторская мастерская

Как устроен учебник, откуда взялись материалы и что изменилось между редакциями.

| Документ | Для чего нужен |
|---|---|
| [Паспорт издания](Паспорт-издания.md) | Даты, статус, публичные изменения и контрольные суммы файлов. |
| [Работа с источниками](Работа-с-источниками.md) | Как связать утверждение с источником, указать ограничения и степень уверенности. |
| [Шаблон урока](Шаблон-урока.md) | Учебный вопрос, объяснение, пример и проверка понимания. |

План, шаблон и исходный стандарт источников сохранены как редакционные документы своего времени. Ранние статусы внутри них не определяют текущий статус публичного издания.
